01 / The lore

The DAW is imaginary. The vibe is not.

MOAI Studio 21 is a joke project made for one very important purpose: to give a Discord profile a custom activity and a little producer-core personality.

The name is a playful nod to FL Studio 21, combined with the internet's favourite emotionally unavailable stone head: 🗿. This is not a real digital audio workstation, and it does not pretend to replace one. No piano roll. No mixer. No 808s were harmed in the making of this landing page.

02 / The signal chain

How it actually works

Under the meme skin, Rich Presence is a Discord feature for showing activity information in a user's profile. This website describes the project; it does not run the activity by itself.

01

Application identity

MOAI Studio 21 has an Application ID configured in the Discord Developer Portal. Uploaded art assets can be referenced by their asset keys.

02

A compatible local RPC client

A separate client running on your computer sets the activity text, state, timestamps, and image keys. The website itself does not do this.

03

Local connection to Discord

The client communicates with the running Discord desktop app through its local RPC/IPC interface. Discord then decides how to render the activity.

04

The profile gets the bit

If the client is connected and activity sharing is allowed, Discord can display the configured presence. Stop the client or clear the activity and the show is over.
